# mod003 — Modificaciones: Dejar de mostrar ID

> Identificador vigente: **mod003 (Dejar de mostrar ID)**.

## Descripción General

Adaptar el sistema existente con cambios visuales, con el objetivo de corregir detalles no contemplados en los requerimientos.

## Criterios de Aceptación

1. En el listado de parques solares, no se debe mostrar el ID del parque solar.
2. En el detalle de parque solar, no mostrar el ID ni del parque solar, ni el ID del nodo, ni el ID del inversor, ni el ID del sensor.

## Reglas de Negocio

- No modificar nada en la carpeta de arnes/prompting/requerimientos ni carpetas dentro de la misma.
